# Miku in 0.1

Guess the Vocaloid song from a 0.1-second clip.

- Five difficulties (Easy → Impossible) plus All, 106 songs
- Type your guess; the box autocompletes English titles, Japanese titles and producers
- Four tries per song: each wrong guess unlocks a longer clip (0.1s, 0.5s, 1s, 3s) for fewer points
- Reroll skips a song

It's one self-contained `index.html`. Clips stream from Apple Music's 30-second previews, so it needs an internet connection.
